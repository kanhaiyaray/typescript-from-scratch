# Project Workflow

1. Create a branch.
2. Write TypeScript code.
3. Compile with TypeScript.
4. Test the generated JavaScript.
5. Stage changes.
6. Commit changes.
7. Push to GitHub.

Example:

git checkout -b feature/new-topic
npm run build
git add .
git commit -m "Add new TypeScript topic"
git push -u origin feature/new-topic
